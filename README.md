# Mue

Change le format de n'importe quel fichier en un seul geste : sélectionne-le dans le Finder, maintiens ⌥ C, glisse vers le format voulu, relâche. Images, vidéos, audio, PDF et documents.

## Télécharger

**[Télécharger Mue pour Mac](../../releases/latest/download/Mue.dmg)** (Mac à puce Apple, macOS 11 ou plus récent)

## Installer

1. Ouvre `Mue.dmg` et glisse **Mue** dans le dossier **Applications**.
2. Ouvre Mue. Au premier lancement, macOS affiche « Apple n'a pas pu vérifier… » : ferme ce message, ouvre **Réglages Système › Confidentialité et sécurité**, descends jusqu'à Mue et clique sur **Ouvrir quand même**.
3. Suis la prise en main : elle demande l'accès au Finder et t'aide à régler ta roue.

C'est la seule fois. Les nouvelles versions s'installent ensuite depuis l'app, d'un clic sur **Mettre à jour**.

---

## English

Convert any file in a single gesture: select it in Finder, hold ⌥ C, slide to the format you want, release.

**[Download Mue for Mac](../../releases/latest/download/Mue.dmg)** (Apple silicon, macOS 11 or later). Drag Mue into Applications. On first launch, macOS warns that Apple could not verify the app: open **System Settings › Privacy & Security** and click **Open Anyway**. Updates then install from the app in one click.
